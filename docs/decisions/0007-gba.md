# 0007: GBA games

- **Status:** Accepted (implemented in `apps/prometheus64`).
- **Date:** 2026-10-29
- **Owner's choices:** one app for both consoles, called Project Prometheus (no "64"); the console is recognised from the game file, never chosen by the player; GBA multiplayer must work like separate consoles (each player on their own), with no lag, so Pokémon trades and battles work.

## How it works

| Part | Where | What it does |
|---|---|---|
| Recognising the console | `src/library.cpp` | A GBA header (fixed byte 0x96 at 0xB2, a valid header checksum at 0xBD) makes a game a GBA game, whatever its file name. Its id is `AGB-<game code>-<version>-<checksum>` |
| The core | `third_party/gpsp` | gpSP (GPL-2) at a pinned commit, built from its sources by this project's CMake, into `cores/gpsp_libretro.dll` |
| Switching cores | `src/app.cpp` (`use_core`) | The app loads the core the game needs when the game starts; the N64 core stays the default |
| Pictures | `src/video.cpp` | Three looks: sharp square pixels at any size (Sharp, the default), xBR-lv2 (Smooth), and the LCD's colours, pixel grid and frame mixing (Handheld) |
| Saves | `savekit`, `src/app.cpp` | One 128 KB save memory, kept as `gba_save.bin` in `Documents\Memories\GBA\<game>`; imports pad smaller files (`.sav` from other emulators) |
| Drive backup | `src/backup.cpp` | The same sync as N64, per console: `Memories/GBA/...` next to `Memories/N64/...` |
| Link play | `src/link.cpp` | gpSP's link messages (libretro netpacket interface) carried over the group's relay, in `prometheus-link` rooms |

## Choices and why

- **gpSP, not mGBA or VBA-M.** gpSP is the libretro GBA core with networked link play: the Pokémon generation 3 link cable mode and the Wireless Adapter, where each console runs on its own and only link messages travel. It is fast (an x86 recompiler) and GPL-2 like the N64 core. Its CPU accuracy is lower than mGBA's (two of the jsmolka CPU tests fail, on its interpreter too), which commercial games don't hit in practice.
- **No lockstep for GBA.** N64 online play runs one game on every computer in lockstep, so everyone waits for the slowest connection. GBA link play is like real consoles with a cable: each game runs at full speed on its own computer, and only the link travels. A trade or battle only waits on the link's own messages, never the game's frames, so the network can't make the game stutter.
- **Built here, not with gpSP's Makefile.** The app's CMake builds the core with the same settings gpSP's Makefile uses on PC. Microsoft's compiler can't build gpSP (GNU assembly), so Windows builds made with it get the core from `tools/build-gba-core-windows.sh` (MinGW-w64), like the N64 core.
- **The open BIOS.** gpSP's built-in open source BIOS replacement is used, so players need no Nintendo BIOS file.
- **Pokémon games get the right link mode.** The app sets gpSP's serial mode from the game code: the Pokémon cable mode for Ruby, Sapphire, Emerald, FireRed and LeafGreen, or the Wireless Adapter for the last three when the player chooses it. Both players need the same; the app tells them when they differ.
- **Sharp pixels and the game's own colours by default.** The first default smoothed the picture (xBR) and corrected the colours toward the GBA's screen. The owner found the sprites and text too distorted and the colours unnatural (the red especially) on a big screen, so both are now choices: Smooth, and Handheld for the GBA's colours.
- **The cartridge clock is the computer's clock.** gpSP's clock can follow emulated frames (and save states) or the host's real time; the app picks real time, so berries grow and daily events turn over while the app is closed, as with a cartridge's battery-backed clock. Loading a save state never turns the clock back.
- **Speeding up: hold Space.** The owner asked for Space as the speed key, as in other GBA emulators. While it's held the game runs at 4x (fast enough to skip walking and text, slow enough to steer), its sound is left out because sped-up sound only stutters, and a small sign shows the speed. It's a keyboard control like Walk, changeable on the Controls screen; a player who had already given Space to another control keeps it there. It's off during link play and events, where the other side expects the game's own pace.
- **Widescreen and N64-only items are hidden** for GBA games.
