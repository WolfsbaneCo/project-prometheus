# Website pages

The project's public pages, for `wolfsbanecompany.com/prometheus/`:

- `prometheus/index.html`: what Project Prometheus and Prometheus 64 are. This is the home page linked from Google's sign-in screen.
- `prometheus/privacy/index.html`: the privacy policy, built from [`docs/legal/privacy-policy.md`](../docs/legal/privacy-policy.md).

Each page is a single file, logo included, so a host only needs the `prometheus` folder copied as it is. Google's sign-in setup needs both links on the domain listed under "Authorized domains" (see [`docs/google-drive-setup.md`](../docs/google-drive-setup.md)).
